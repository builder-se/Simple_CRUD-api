# 📌 Case Study

## 🛠️ Simple CRUD API

### 📖 Overview

As part of the **FlyRank Backend AI Engineering Internship (Week 2)**, I built my first RESTful CRUD API. This project strengthened my understanding of backend fundamentals while giving me hands-on experience designing, implementing, and testing API endpoints.

---

## 🎯 The Problem

The challenge was to create a backend service capable of performing the four essential CRUD operations:

* ➕ Create
* 📖 Read
* ✏️ Update
* 🗑️ Delete

The objective wasn't simply to finish an assignment—it was to understand how modern backend APIs are designed and organized.

---

## ⚙️ What I Did

I built the project using **Python** and **FastAPI**, focusing on writing clean, maintainable backend code.

### Key Decisions

* ✅ Structured the project with a clean folder hierarchy.
* ✅ Built RESTful endpoints following standard HTTP conventions.
* ✅ Tested every endpoint to verify functionality.
* ✅ Used FastAPI's interactive Swagger documentation for testing.
* ✅ Managed version control using Git.
* ✅ Published the project on GitHub.

### Technologies Used

| Technology | Purpose                      |
| ---------- | ---------------------------- |
| Python     | Backend programming language |
| FastAPI    | REST API framework           |
| Git        | Version control              |
| GitHub     | Source code hosting          |
| Swagger UI | API documentation & testing  |

---

## 🎉 Outcome

The project successfully fulfilled the FlyRank Week 2 challenge requirements.

### Skills Strengthened

* REST API Design
* CRUD Operations
* FastAPI Fundamentals
* HTTP Methods
* API Testing
* Git & GitHub Workflow
* Backend Project Organization

### Reflection

This project marked an important milestone in my backend engineering journey. Beyond completing the assignment, it gave me confidence in building APIs and reinforced the importance of writing clean, understandable code.
